# Project Context

## Purpose
Consumer PWA scorekeeping for cricket, focused on simple, fast match tracking for everyday users.

## Tech Stack
- Next.js (App Router)
- React
- TypeScript

## Project Conventions

### Code Style
- ESLint + Prettier as the source of truth.
- Favor consistent naming and formatting over custom style rules.

### Architecture Patterns
- App Router for UI routing.
- API routes for backend endpoints.

### Testing Strategy
- Unit and integration tests for core logic and flows.

### Git Workflow
- Trunk-based development with short-lived branches.

## Domain Context
- Cricket scoring rules and match flow are primary domain drivers.

## Important Constraints
- Offline-first PWA experience is required.

## External Dependencies
- None.
